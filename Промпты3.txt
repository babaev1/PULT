нужно изменить режим автоматического засыпания смартфона при работе приложения. Переход в режим засыпания должен происходить только по нажатию на кнопку засыпания человеком. В режиме, когда приложение неактивно, то засыпание устройства должно происходить в штатном режиме.  

Резюме изменений в файле MainActivity.kt:
1.
Добавлен импорт: android.view.WindowManager для работы с параметрами окна.
2.
Установлен флаг: В метод onCreate добавлена команда window.addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON).
Результат:
•
Экран не гаснет, пока приложение открыто (идеально для управления джойстиком).
•
Автоматическое засыпание отключается только для вашего приложения.
•
Штатный режим засыпания сохраняется, если пользователь свернет приложение или заблокирует телефон вручную.
